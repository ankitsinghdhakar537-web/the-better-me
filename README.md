# The Better Me 🌿

A personal growth and lifestyle blog featuring inspiring stories, self-improvement, mental wellness, relationships, and life lessons in English and Hindi.

## 🌐 Live Website

[**Visit The Better Me →**](https://ankitsinghdhakar537-web.github.io/the-better-me/)

## ✨ Features

- English and Hindi stories
- Category-based story filtering
- Full story popup
- Clean, aesthetic and responsive design
- Newsletter subscription demo

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 👨‍💻 About the Project

The Better Me is a space for thoughtful stories, personal growth, and everyday life lessons designed to help readers understand themselves a little better.
